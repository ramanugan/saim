## Purpose

Proporciona un modelo de navegación central unificado y coherente por categorías para mejorar la experiencia de usuario y facilitar la escalabilidad del menú.

## ADDED Requirements

### Requirement: Estructura Categórica
El Drawer lateral SHALL agrupar las opciones de navegación en secciones lógicas (Catálogos, Seguridad, etc.).

#### Scenario: Visualización del menú
- **WHEN** el usuario despliega el menú lateral principal
- **THEN** observa una jerarquía visual separada por títulos y submenús que agrupan lógicamente los CRUDs.
